# Báo cáo cá nhân — Hà Nhật Khánh Duy

## 1. Thông tin sinh viên

- Họ và tên: Hà Nhật Khánh Duy
- Mã học viên: 2A202602031

## 2. Phần công việc phụ trách

- Implement các node trong support-ticket workflow.
- Dùng structured output của LLM để phân loại intent.
- Sinh câu trả lời bằng LLM dựa trên query, tool result và approval context.
- Xử lý tool, evaluation, clarification, risky action, approval, retry và dead letter.

## 3. File liên quan

- `src/langgraph_agent_lab/nodes.py`

## 4. Kết quả thực hiện

- Classifier áp dụng ưu tiên `risky > tool > missing_info > error > simple`.
- Tool mô phỏng lỗi tạm thời để kiểm tra retry loop.
- Retry chỉ tăng counter tại một node và dừng ở `max_attempts`.
- Hành động rủi ro phải được approval trước khi gọi tool.
- Mọi node trả partial update, không mutate input state.
- Lỗi provider được ghi vào audit trail và có controlled fallback.

## 5. Tự đánh giá

Các node có boundary rõ và đủ audit event. Cải tiến tiếp theo là thay mock tool bằng service thật,
thêm timeout, idempotency key và exponential backoff.
